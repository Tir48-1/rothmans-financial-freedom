# ROTHMANS — Financial Freedom House

Static demo website for GitHub Pages.

## Publish

1. Create a new GitHub repository, for example `rothmans`.
2. Upload all files from this folder to the repository root.
3. Make sure the default branch is `main`.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **GitHub Actions**.
6. Push/commit the files. The workflow will deploy automatically.

Your public URL will usually be:

`https://YOUR-GITHUB-USERNAME.github.io/rothmans/`

## Files

- `index.html` — main site
- `rothmans_hero_video.mp4` — hero video
- `rothmans_logo.svg` — logo
- `.nojekyll` — prevents Jekyll processing
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment
